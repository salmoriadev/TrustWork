# Security Policy

## Supported version

Only the latest commit on `main` is supported. TrustWork is a testnet engineering demo, not a production financial service.

## Reporting

Please use GitHub private vulnerability reporting for `salmoriadev/TrustWork`. Do not open a public issue containing an exploit, secret, wallet material, or personal data.

Include the affected component, reproduction steps, impact, and a safe proof of concept. Do not test against accounts or infrastructure you do not own.

## Scope notes

The public demo uses Base Sepolia test assets with no monetary value. The contract has not been externally audited, original evidence files are not hosted, and mainnet use is explicitly unsupported.

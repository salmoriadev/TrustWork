# Contributing to TrustWork

TrustWork is an early-access portfolio project. Small, focused issues and pull requests are welcome.

1. Use Node 20, Python 3.12, uv, and Foundry 1.7.1.
2. Create a branch from `main` and keep changes focused.
3. Never commit provider credentials, wallet secrets, evidence content, or populated `.env` files.
4. Run `./scripts/check.sh` before opening a pull request.
5. Explain user-visible behavior, security implications, and test coverage in the pull request template.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

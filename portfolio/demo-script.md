# 30–45 second demo script

**0–6s — Landing.** “TrustWork makes freelance milestone agreements inspectable: scope, testnet escrow, evidence integrity, and reputation in one system.”

**6–14s — Anonymous marketplace.** Open `/app` and select a real indexed Base Sepolia contract. “The marketplace is useful without a wallet; these cards come from confirmed contract events, not frontend fixtures.”

**14–22s — Escrow.** Open the contract timeline. “FastAPI projects the escrow state into PostgreSQL using an idempotent confirmed-block cursor and replay window.”

**22–31s — Evidence integrity.** Select a small non-sensitive file. “The browser hashes the file. TrustWork receives metadata and the digest only; the original stays with me.”

**31–38s — Optional wallet.** Connect a testnet wallet and sign the TrustWork SIWE message. “Wallet actions are optional, chain-gated to Base Sepolia, and authenticated with a short-lived in-memory token.”

**38–45s — BaseScan proof.** Show the confirmed transaction link. “The UI waits for the receipt, tracks replacement or revert states, synchronizes that exact escrow block, and links to public BaseScan proof.”
